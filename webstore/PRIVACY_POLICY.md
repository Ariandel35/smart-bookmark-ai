# Marko 隐私政策

最后更新：2026-05-31

Marko 仅在完成书签整理功能所必需的范围内处理数据。

## 1. 我们读取哪些数据
- 你的 Chrome 书签标题、URL 和当前文件夹路径
- 你在扩展中填写的模型服务商、Base URL、模型名、速度模式、自定义 Prompt、白名单域名
- 由扩展创建的本地快照备份与任务状态

## 2. 我们如何使用这些数据
- 开启完整链接检查时，用于扫描书签链接是否明显失效
- 仅在完整模式预览或已开启自动整理且本地规则、缓存无法覆盖时，用于调用你自己配置的大语言模型服务生成书签分类结果；完整模式还会在分类前生成全局目录方案
- 用于在应用预览方案、自动整理重建前创建本地快照备份；恢复旧备份前也会先为当前书签状态创建本地快照
- 用于在扩展界面中显示任务进度、删除记录和未处理项目

## 3. 数据会发送到哪里
- 书签标题、URL、现有路径和自定义 Prompt 只会在完整模式预览或已开启自动整理且仍需要模型分类时，发送到你选择的模型服务商
- 应用已保存的预览方案会直接本地重建，不会再次请求模型
- 快速模式会在预览和整理流程中跳过失效链接检测、单独目录规划请求和模型分类
- 完整模式会直接访问书签对应的网站以判断其状态，并在需要模型分类时先请求全局目录方案

## 4. 数据存储位置
- API Key 与扩展配置保存在浏览器本地的 `chrome.storage.local`
- 本地快照备份，包括恢复前创建的当前状态快照，保存在浏览器本地的 IndexedDB
- 分类缓存和死链缓存保存在浏览器本地，用于加快重复整理
- 扩展开发者不会将这些数据上传到自有服务器

## 5. 你的控制权
- 你可以随时修改或删除 API 配置
- 你可以选择快速模式减少权限并加快预览，也可以选择完整模式在分类前检测链接
- 你可以使用白名单跳过特定网站
- 你可以关闭自动整理
- 你可以删除备份或恢复旧版本书签；恢复前会先为当前书签状态创建新的本地快照
- 你可以在 Chrome 扩展权限设置中撤销 API 域名或网站访问权限
