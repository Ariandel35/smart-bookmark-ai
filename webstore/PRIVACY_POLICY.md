# TidyMarks AI 隐私政策

最后更新：2026-04-19

TidyMarks AI 仅在完成书签整理功能所必需的范围内处理数据。

## 1. 我们读取哪些数据
- 你的 Chrome 书签标题、URL 和当前文件夹路径
- 你在扩展中填写的 API Provider、Base URL、模型名、自定义 Prompt、白名单域名
- 由扩展创建的本地快照备份与任务状态

## 2. 我们如何使用这些数据
- 用于扫描书签链接是否明显失效
- 用于调用你自己配置的大语言模型服务，生成书签分类结果
- 用于在整理前创建本地快照备份，并在需要时恢复
- 用于在扩展界面中显示任务进度、删除记录和未处理项目

## 3. 数据会发送到哪里
- 书签标题、URL、现有路径和自定义 Prompt 会在你主动开始整理，或你开启自动整理后，发送到你选择的模型服务商
- 失效链接检测会直接访问书签对应的网站，以判断其状态

## 4. 数据存储位置
- API Key 与扩展配置保存在浏览器本地的 `chrome.storage.local`
- 本地快照备份保存在浏览器本地的 IndexedDB
- 扩展开发者不会将这些数据上传到自有服务器

## 5. 你的控制权
- 你可以随时修改或删除 API 配置
- 你可以使用白名单跳过特定网站
- 你可以关闭自动整理
- 你可以删除备份或恢复旧版本书签
- 你可以在 Chrome 扩展权限设置中撤销网站访问权限
