# GitHub 链接模板

推送到 GitHub 公开仓库后，把下面这些地址填到 Chrome Web Store：

- 主页网址
  - `https://github.com/<your-name>/<your-repo>`
- 支持网址
  - `https://github.com/<your-name>/<your-repo>/issues`
- 隐私政策网址
  - `https://github.com/<your-name>/<your-repo>/blob/main/PRIVACY.md`

如果你启用了 GitHub Pages，也可以把隐私政策改成你自己的 Pages 地址。
