# Smart Bookmark AI - Chrome Web Store 文案

## 单一用途
使用大语言模型帮助用户整理 Chrome 书签：扫描失效链接、移除明显重复项，并将剩余书签重建为更清晰的分类结构。

## 简短描述
用 AI 重新整理 Chrome 书签，自动清理明显重复和失效链接，重建更易找的分类结构。

## 详细描述
Smart Bookmark AI 是一个面向重度书签用户的整理工具。

它会先为你创建本地快照备份，再读取书签标题、URL 与当前路径，调用你自己配置的模型服务完成语义分类，并最终把整理好的目录结构直接重建到书签根目录。

核心能力：
- 连接 OpenAI、DeepSeek、MiniMax 或 Ollama
- 自定义 Base URL、API Key、模型名与 Prompt
- 分批处理大量书签，减少长任务中断和模型超时
- 先扫描明显失效的链接，再进行 AI 分类
- 自动识别明显重复书签并移除冗余入口
- 白名单域名跳过整理
- 每次整理前自动创建本地快照备份
- 支持手动备份、恢复和删除备份
- 自动静默整理
- 明细面板可查看未处理与删除记录

隐私说明：
- 只有在你主动开始整理，或开启自动整理后，相关书签信息才会发送到你选择的模型服务商
- API Key 和备份快照保存在浏览器本地
- 失效链接检测会向书签对应网站发送网络请求
