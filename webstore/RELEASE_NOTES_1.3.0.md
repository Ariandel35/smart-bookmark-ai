# Smart Bookmark AI 1.3.0 Release Notes

## 中文更新公告

Smart Bookmark AI 1.3.0 是面向 Chrome Web Store 发布的完整升级版，这次更新重点围绕“更清晰的整理流程、更少的界面干扰、支持中英文”展开。

本次更新：
- 新增中英文界面支持，可根据 Chrome 语言自动切换
- 优化整理流程，调整为“先预览，确认后再整理”
- 优化弹窗和设置中心，保留更关键的信息和操作
- 增强全局分类规划与分批处理，减少分类漂移
- 增加分类缓存和死链缓存，加快重复整理速度
- 增加白名单网站选择、受保护根目录和域名目录规则
- 完善本地快照备份、恢复和删除能力
- 补充 GitHub 文档、商店文案和上架宣传素材

适合提交到商店后台的简短版本：

Smart Bookmark AI 1.3.0 带来更成熟的发布版体验。此次更新新增中英文界面支持，整理流程调整为“先预览、再确认执行”，并继续优化备份、分类规划、缓存复用和整体界面，让大体量书签整理更安全、更稳定、更容易上手。

## English Update Note

Smart Bookmark AI 1.3.0 is the release-focused upgrade for Chrome Web Store publication. This update focuses on a clearer organize flow, a cleaner interface, and bilingual support.

Highlights:
- Added English and Simplified Chinese interface support
- Changed the organize flow to preview first, then confirm before rebuilding
- Refined the popup and settings center to keep only the most important actions
- Improved global taxonomy planning and chunked processing for more stable results
- Added classification cache reuse and dead-link cache for faster reruns
- Added whitelist website selection, protected root folders, and domain folder rules
- Improved local snapshot backup, restore, and delete flows
- Added refreshed GitHub docs, store listing copy, and Chrome Web Store promo assets

Short version for store release notes:

Smart Bookmark AI 1.3.0 brings a cleaner release-ready experience. This update adds English and Simplified Chinese support, changes the organize flow to preview first before confirmation, and further improves backups, taxonomy planning, cache reuse, and overall usability for large bookmark libraries.
