# Chrome Web Store 审核备注

## 权限说明
- `bookmarks`
  - 读取、移动、删除和重建书签结构
- `storage`
  - 保存 API 配置、任务状态、白名单和本地备份记录
- `alarms`
  - 支持自动静默整理和分批任务调度
- `optional_host_permissions` (`http://*/*`, `https://*/*`)
  - 仅在用户显式授权后使用
  - 用于访问用户选择的模型 API
  - 用于检测书签链接是否失效

## 数据流说明
- 扩展不会把数据发送到开发者自有服务器
- 扩展只会把整理所需书签信息发送到用户自行配置的模型服务商
- 失效链接检测直接访问用户书签对应的网站
- API Key、配置和快照备份只保存在本地浏览器

## 审核建议
- 在商店后台的单一用途里填写：使用 AI 整理 Chrome 书签
- 在隐私披露中明确说明：
  - 会读取书签
  - 会访问用户选择的第三方 AI 服务
  - 会访问书签指向的网站以检测失效链接
  - 数据仅保存在本地，不上传到开发者服务器
