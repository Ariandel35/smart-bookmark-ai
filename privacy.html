隐私说明

Data Use

数据使用范围

读取的本地数据
书签标题、URL、当前文件夹路径、插件设置、备份快照。
发送到第三方的数据
只有在你主动整理书签或开启自动整理时，书签标题、URL、现有路径和自定义 Prompt 才会发送到你选择的模型服务商。
失效链接检测
整理流程会直接向书签对应的网站发送 HEAD / GET 请求，用于判断链接是否失效。
本地存储
API Key、Provider、模型名、白名单和备份快照都保存在你的浏览器本地存储与 IndexedDB 中。

Control

你可以控制的内容

授权网站访问
整理书签和自动整理前，需要你显式授权网站访问权限。你也可以稍后在 Chrome 扩展权限里撤销。
白名单与待手动分类
白名单域名不会被自动整理；状态不明确的书签会进入“待手动分类”。
备份与恢复
整理前会先创建本地快照备份。你可以在设置页管理备份并恢复旧版本。
